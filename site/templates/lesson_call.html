# Введение в экспоненциальный рост и визуализацию данных В этом мини‑уроке вы поймёте, как описывается экспоненциальный рост, как читать и строить простые графики, а также немного потренируетесь с формулами и кодом. --- ## 1) Что такое экспоненциальный рост Экспоненциальный рост описывается моделью $N(t)=N_0 e^{rt}$, где $N_0$ — начальное значение, $r$ — темп роста (в единицах времени), $t$ — время. Типичный индикатор — **время удвоения**: $T_d=\dfrac{\ln 2}{r}$. ### Квиз: формула времени удвоения [[quiz multiple="false" after_ok="Верно! Время удвоения равно ln(2)/r." after_fail="Не совсем. [[code language="javascript" filename="growth.js"]] /\*\* * Генерирует значения N(t) = N0 \* exp(r \* t) для t=0..T, шаг dt \*/ export function expGrowth({ N0 = 1, r = 0.3, T = 10, dt = 1 } = {}) { const xs = []; const ys = []; for (let t = 0; t <= T + 1e-9; t += dt) { xs.push(Number(t.toFixed(6))); ys.push(Number((N0 \* Math.exp(r \* t)).toFixed(6))); } return { x: xs, y: ys }; } // пример: const demo = expGrowth({ N0: 2, r: 0.25, T: 5, dt: 0.5 }); console.log(demo); [[/code]] --- ## 8) Контрольные вопросы (OPEN) [[open answer="экспоненциальный рост|exponential growth" ignore_case="true" normalize="true" after_ok="Верно!
